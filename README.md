# RoadPulse

# 🚦 Traffic Flow Prediction using Machine Learning

This project predicts traffic volume at road junctions using historical traffic data from Kaggle.

## 📌 Features
- Predicts number of vehicles
- Uses Random Forest Regressor
- Peak hour traffic analysis
- 24-hour traffic forecast
- Feature importance visualization

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Kaggle Dataset

## 📊 Output
The model predicts traffic volume based on:
- Junction
- Hour
- Day
- Month
- Day of Week

Example:
Predicted Vehicles = 15

Kaggle Traffic Prediction Dataset
